### v⁰ 提取口径（本轮已定：照用实测值）

1. 逐帧速度 → **中值滤波**（窗口 5 帧）压掉追踪跳变（原始数据最大瞬时速度 10.25 m/s，是异常值）；
2. 1 s 矩形滑动平均；
3. 取 **p90** 作为该行人的期望自由速度 v⁰_i。

结果：中位 **2.1 m/s**，范围 1.60–4.27。**明显高于论文默认的 1.34 m/s，这是照用实测值的直接后果**：
这批受试者空闲时走得快（自由穿越约 9.5 s），实验实际 17 s，差额 ~7.5 s 就是冲突延误 ——
正好是设计文档 §5「只有当 ΔT 足够大时绕行才占优」的定量落点。
命令行保留 `--v0-scale` 作为把 v⁰ 整体缩放的逃生口，默认 1.0。

## 3. 模型结构

### 3.1 椭圆几何与间隙距离

行人 i 用椭圆表示：中心 `p_i`，**长半轴沿当前运动方向 `e_i`**，半轴 `a = 0.18 m`（论文 §4：`τ_a`
与 `T` 作用相同，作者丢弃 `τ_a` 取常数）；**短半轴随速度变化**

```
b_i = b_min + (b_max − b_min) / (1 + exp(β (V_i − γ)))
```

方向 `û` 上椭圆边界的半径（把 û 投影到椭圆自身坐标系后取极径）：

```
r_i(û) = 1 / sqrt( cos²θ / a² + sin²θ / b_i² ),   θ = ∠(û, e_i)
```

**边界到边界的间隙**（沿两心连线量，这就是"广义"那一步的实质）：

```
d_ij = ‖p_j − p_i‖ − r_i(û_ij) − r_j(û_ji),   û_ij = (p_j − p_i)/‖p_j − p_i‖
```

分离时 d > 0，重叠时 d < 0。

### 3.2 Module C —— GCFV 局部运动

**邻居集合**（两个，用途不同）：

- 方向用**视域** `N_i^Area = { j : e_i·e_ij < 0 或 e⁰_i·e_ij < 0 }` —— 当前朝向的前半平面与期望方向
  的前半平面之并集。墙的判据：整个墙段都落在该区域内才计入（圆形墙见 §3.5）。
- 速度用**运动带** `J_i = { j : e_i·e_ij ≤ 0 且 |e_i^⊥·(p_j − p_i)| ≤ b_min }`。
  论文椭圆版没有给新公式，只说灰色搜索带宽度取 `2 b_min`，这里据此实现。

**速度子模型**（第一序，天然无碰撞）：

```
V_i = min{ v⁰_i,  max(0, d_i / T),  max(0, dw_i / T) }
d_i  = min_{j∈J_i} d_ij
dw_i = min_{v∈JW_i} d_iv / cos α_v
```

**方向子模型**（一阶，论文 Eq. 7 + 15 的两步式）：

```
E_i = u( e⁰_i + Σ_{j∈N_i^Area} R(d_ij) e^N_ij + Σ_w R_w(d_iw) e^N_iw )      u 为归一化算子
de_i/dt = (E_i − e_i) / τ
```

影响方向 `e^N_ij` 由障碍落在期望方向的哪一侧决定：

```
C_j = e_ij · e^{0⊥}_i        (e^{0⊥}_i = e⁰_i 逆时针转 90°)
C_j > 0 → e^N_ij = +e^{0⊥}_i
C_j < 0 → e^N_ij = −e^{0⊥}_i
C_j = 0 → 随机取一侧（正面相遇时的侧身让行）
```

**位置更新**：`p_i += V_i · e_i · Δt`（注意速度方向用的是平滑后的 e_i，不是 e⁰_i）。

**影响函数 R（⚠ 与论文印刷式不同，见 §9）**：

```
R(d)   = k   · exp(−d / D)
R_w(d) = k_w · exp(−d / D_w)
```

### 3.3 Module A —— 路线 / 绕行决策

候选三条：`straight`、`left`、`right`。左右绕行用**弦中点横向偏移**定义：

```
d⃗ = g_i − p_i,  D = ‖d⃗‖,  û = d⃗/D
m = p_i + 0.5 d⃗                      弦中点
n̂ = (−û_y, û_x)                       左法向
w_left  = m + δ n̂
w_right = m − δ n̂
w_straight = g_i
```

`δ = 2.0 m` 为绕行幅度（新参数）。注意直线路径恰好穿过圆心，所以左右绕行等价于
「从圆心两侧绕开」，这与场景的冲突结构一致。

```
L_i(R) = ‖p_i → w_R‖ + ‖w_R → g_i‖
```

**预计延误 ΔT_i(R)** —— 用 GCFV 自己的速度子模型估（本轮已定）：

```
预测窗口  H(R) = min( L_i(R)/v⁰_i , H_cap )            按路线取，见下
沿候选路线以 v⁰_i 前进取样：t = 0.2, 0.4, …, H(R)
  自身位置   x(t) = 沿 R 前进 v⁰_i · t 弧长处的点
  自身朝向   取当前 e_i（不为估 ΔT 再算一遍方向子模型）
  邻人集合   N_T = { j : ‖p_j − p_i‖ ≤ 10 m }           半径筛，不用视域
  邻人位置   y_j(t) = p_j + w_j · t                     见下面的外推速度
  间隙       d(t) = min_{j∈N_T} d(x(t), y_j(t))         同一套椭圆间隙
  速度       V(t) = min{ v⁰_i, max(0, d(t)/T) }         GCFV 速度子模型
  ΔT_i(R) = Σ_t (1 − V(t)/v⁰_i) · 0.2
```

邻人集合刻意用**半径筛而不是视域筛**：视域是「我现在朝哪看」，而 ΔT 要回答的是
「我沿这条路走下去会撞上谁」，包括我还没转向他那边的人。

**外推速度 `w_j` 取「朝 j 自己的目标、以 v⁰_j 走」，不是 `v_j`。** 实现时先用当前速度
外推，结果路线选择完全失效（主模型退化成 baseline）：实测起步时人员速度中位只有
0.35 m/s，按当前速度外推等于预测「所有人都站着不动」，圆心附近永远估不出拥堵，ΔT≈0。
已到达目标的人（站住不动）例外，外推速度取零。

**预测窗口取该路线的自由通行时间 `L/v⁰`，封顶 12 s，不是固定 3 s。** 同样是用固定值
试出来的：三条路线只在弦中点附近才分岔，而中点距起点约 10 m、以 v⁰ 走要 4 s 以上 ——
窗口短于走到中点的时间，就根本看不到圆心拥堵，三条路线的 ΔT 全是「起步阶段人人拥挤」
且几乎相等，路线选择再次退化成比谁短。窗口覆盖全路线后主模型的绕行人数从 7 升到 12。

路线层与运动层因此**同源**：决策所依据的延误，就是局部运动模型真会产生的延误。
除预测时长 H 外没有额外参数。

```
C_i(R) = α_i · L_i(R) / v⁰_i  +  β_i · ΔT_i(R)
R_i*   = argmin_R C_i(R)
```

**决策节奏**：每 `ΔT_route = 1.0 s` 决策一次（设计文档 §11 给的是 0.5–2.0 s）。
两条防抖规则：① 新路线代价要比当前路线低 **5% 以上**才切换；② 剩余距离 < 1 m 时固定直行。

### 3.4 Module B —— 期望方向

```
R* = straight → e⁰_i = (g_i − p_i)/‖g_i − p_i‖
R* = left/right → e⁰_i = (w_R − p_i)/‖w_R − p_i‖
```

与 Module C 完全解耦：Module C 只接收 `e⁰_i`，不知道路线是怎么选出来的（baseline 因此可以
在只把 `e⁰_i` 恒设为指向目标的情况下复用整个局部运动层）。

### 3.5 圆形边界（解析处理，不用折线近似）

**边界半径取 12 m，不是设计文档 §9 写的 10 m。** 实验在开阔场地进行，10 m 圆环是**行走路线**
而不是围墙 —— 实测 64 人的起点半径就是 9.72~10.52 m，终点也落在环上。把墙设在 10 m 会：
① 让站在环上的人与墙重叠、被永久冻住；② 让墙项 `dw/T` 限制环上的正常行走。
取 12 m（实测最大半径 10.52 m + 余量）后，墙项只兜底、不干扰圆环附近的行为。

实验区是半径 `R = 12 m` 的圆，GCVM 的墙项需要的是「离人最近的墙点」，对圆来说有解析解：

```
C_i   = R · p_i / ‖p_i‖              圆心到人的射线与圆的交点
e_iv  = (p_i − C_i)/‖p_i − C_i‖      从墙指向人
α_v   = ∠(e_i, −e_iv)
d_iv  = ‖p_i − C_i‖ − r_i(û_iv),   û_iv = (C_i − p_i)/‖C_i − p_i‖
```

论文判墙是否进入视域用的是「墙的两个顶点都在视域内」，圆墙没有顶点，改用等价判据：
**最近点 `C_i` 落在 §3.2 的视域内才计入方向项**。速度项 `dw_i` 不做视域筛选（只看运动带）。

`cos α_v` 在 α_v → 90° 时趋于零，`dw_i` 发散 —— 这正是原意：贴着墙平行走的人不受墙限速。
实现时对 `cos α_v` 取下限保护（如 0.1）避免除零。

设计文档 §9 给的三选一，这里选**「墙项 + 边界投影」**：墙项提供连续排斥，另外每步把
`‖p_i‖ > R` 的人投影回圆上，保证不会明显穿出实验区域。

### 3.6 到达与停止

`‖p_i − g_i‖ < 0.3 m` → `V_i = 0`，位置冻结，**但仍然参与他人的邻居集合**（实测末态 64 人
全部静止站立，站着的人本身就是障碍物）。

## 4. 仿真循环与数值设置

```
读实验数据 → 初始化（位置/速度/方向/目标/v⁰）
repeat 425 步（Δt = 0.04 s）:
    if t 是路线决策时刻:  Module A → Module B → e⁰_i
    邻居搜索（视域 / 运动带）
    Module C: 速度子模型 + 方向子模型（显式欧拉）
    边界投影
    p_i += V_i · e_i · Δt
→ 输出轨迹 → 评估
```

- 初值：`p_i(0)` = 实验第 37 帧位置；`v_i(0)` = (第 38 帧 − 第 37 帧)/0.04；
  `e_i(0)` = `v_i(0)` 单位化，若为零向量则指向目标
- 目标：`g_i = −p_i(0)/‖p_i(0)‖ × 10 m`
- 积分：显式欧拉，**并行更新**（所有人同时用 t 时刻的邻居状态算 t+1，不串行化）
- 随机性：只用固定种子（`C_j = 0` 的侧身选择、α/β 的个体抖动），保证可复现

## 9. 已知与论文的偏差（实现时按本节，不按论文印刷式）

**R(d) 的符号。** 论文圆形版印的是 `R(s) = k·exp((ℓ − s)/D)`（随距离**衰减**），
椭圆版印的是 `R(d) = k·exp(d/D)`，而 d 是分离时为正的边界间隙 —— 加号会让影响**随距离增长**，
与圆形版的单调性相反，等于把"排斥"变成了"吸引"。论文既未推导两者的换算，也未讨论单调性。

判定为**印刷笔误**，证据三条：

1. 论文自身称 R 为 "repulsive function"（排斥函数），排斥必然随距离衰减；
2. 同一批作者在 *Prolonged Clogs in Bottleneck Simulations*（[arXiv:2105.03954](https://arxiv.org/abs/2105.03954)）
   中复述同一模型时写作 `k·exp(−s_ij/D)`，带负号；
3. 速度子模型 `V = min{v⁰, max(0, d/T)}` 明确是 d 越大越快，说明 d 分离时为正 —— 若 R 也随 d 增长，
   两人越远方向影响越大，模型不成立。

**实现取 `R(d) = k·exp(−d/D)`、`R_w(d) = k_w·exp(−d/D_w)`。**

其余偏差：椭圆版的邻居搜索域论文只给了带宽 `2 b_min` 没有给公式，按 §3.2 实现；圆形墙的
「最近点」用解析解而非折线段近似（论文的墙是直线段，本场景是圆）。

week02/model/detour_gcfv/
    data.py       实验数据读取、起始状态、目标点、逐人 v⁰ 提取

数据读取与模型完全解耦（`data.py` 的产物是纯数组，不含文件路径）。

| d_center 中位 (m) | 1.62 | **0.46** | 0.56 |
| 直穿（d_center<1 m）人数 | 22 | **52** | 57 |
| 绕行（d_center≥1 m）人数 | 42 | **12** | 7 |

**结论：到达时间、速度、终点位置都对得上，但「圆心避让」这个核心现象严重偏少。**
主模型确实比 baseline 多绕行（12 对 7），方向是对的，但离实验的 42 人差得很远。
