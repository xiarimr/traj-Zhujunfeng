这个项目研究少量行人和车辆相向进入窄路时，如何通过侧移、减速和等待完成交会。人车共用运动方程与交互策略，差异由尺寸和运动能力参数表达。场景包括等宽直路、局部缩窄道路和圆环向心穿越，并提供社会力模型对照。

1. 人和车如何用同一个模型描述

状态与主体尺寸

每个主体的状态为 z = (s, y, u, w)：s 是纵向位置，y 是横向位置，u ≥ 0 是沿行进方向的速度，w 是横向速度。d = +1 / −1 表示相反的行进方向。代码中的 x 对应这里的 s。

行人和车辆都用长 l、宽 b 的矩形包络表示，包络不随运动旋转。道路由长度和宽度函数 W(s) 描述，边界为 ±W(s)/2。缩窄道路使用分段线性宽度；向心实验中各主体朝向由初始圆周位置确定。

参数 行人默认值 车辆默认值 对行为的影响
长 × 宽 0.5 × 0.6 m 4.5 × 1.8 m 决定占用空间和接触判定
期望/初始速度基值 1.3 m/s 3.0 m/s 决定自由行走与行驶速度
最大纵向加速度 1.2 m/s² 1.5 m/s² 限制恢复速度
最大制动减速度 2.0 m/s² 3.0 m/s² 决定停车所需空间
横向速度上限 0.7 m/s 默认 0；侧移对照为 0.2 m/s 决定是否、以及多快能靠边
横向加速度上限 1.0 m/s² 0.4 m/s² 防止横向速度瞬间变化
纵向/横向松弛时间 0.7 / 0.8 s 0.7 / 0.8 s 控制接近期望速度、横向目标的快慢
质量 70 kg 1500 kg 当前仅保存为元数据

初始速度在基值上作 ±8% 的种子控制扰动。完整默认值、单位和扫描范围见参数表。

为什么同一模型会表现为“人绕行、车减速”

模型读取每个主体的尺寸、制动能力、横向速度上限和指定避让侧，不根据“行人/车辆”标签切换运动方程。行人横向能力较强，可以较快移到另一侧；车横向能力较弱或为零，主要通过减速、停车留出时间。双方都计算避碰响应，不假设另一方必定让路。

把车辆的 vehicle_lateral_speed 从 0 改为 0.2，同一控制器就允许车辆缓慢靠边。默认实验中车辆根据道路最窄宽度预先靠边，行人从与车相同的横向位置迎面走来；“车辆居中不动”和“居中后允许侧移”另做对照。

质量不直接决定谁让谁，也没有“轻者必须避让重者”的路权规则。当前加速度、制动和侧移能力已经直接给定；若以后引入驱动力，可用 a_max = F_max / m 表达质量对机动能力的影响。

2. 一次相向交会如何处理

主模型 reciprocal 由期望运动、固定选边、宽度相关慢行和互惠制动组成。两边执行同一套规则。

① 识别冲突，并决定横向目标

控制器检查附近的相向主体，探测距离由双方期望速度与 6 s 前瞻时间计算，最小为 8 m。使用期望速度是为了避免减速后探测范围缩小、反复丢失同一冲突。

发生交互时，主体按预设的 side 移向前方可预见窄断面的安全边界：默认行人取 +y 侧、车辆取 −y 侧。选边保持到对方尾部和纵向间距都通过；若仍有其他相向主体，则继续保持。没有相向交互后，恢复初始横向路径 home_y。

横向目标速度为：

w_des = clip((y_target − y) / tau_y, −w_max, +w_max)

随后施加横向加速度限制，以及接近目标时的停止距离限制，防止横向速度跳变和越过目标。w_max = 0 时保持当前横向位置。

② 空间越紧，交会目标速度越低

设前方最窄宽度为 W_look，两主体宽度为 b_i、b_j，每侧墙边裕度为 m_wall，双方侧向间距为 g_lat，则额外空间为：

q = W_look − b_i − b_j − 2 m_wall − g_lat
f(q) = 0.35 + 0.65 × clip(q / 0.60 m, 0, 1)
u_target ≤ encounter_speed × f(q)

默认 encounter_speed = 1.0 m/s。目标纵向速度还受总速度预算约束，侧移时不会把完整期望速度同时用在纵向和横向。这里的“窄路慢行”是显式行为假设，因此临界宽度附近变慢不能全部解释为实验自行发现的规律。

③ 横向尚未分开时，双方同时减速

横向净间距为 |y_i − y_j| − (b_i+b_j)/2。只有当前净间距与下一步外推净间距都达到 g_lat，才解除该对主体的相向停车约束；不会因为“已经打算绕行”就提前放行。

对尚未分离的相向主体，D 表示前向包络之间的纵向净距再减去静止间距，双方各使用一半剩余距离规划停车：

u T + u² / (2 a_brake) ≤ 0.5 × max(D, 0)
u_safe = sqrt((a_brake T)² + a_brake × max(D, 0)) − a_brake T
T = 0.6 s + Δt

遇到多个主体时，取所有安全速度上限中的最小值。同向跟随使用把前车视为静止障碍的保守限制，此时可使用完整剩余距离，而非一半。T 是规划余量，本版没有实现独立的感知延迟。

实际减速仍不能超过 a_brake：若起点太近或初速太高，控制器会尽力制动，但仍可能发生碰撞。模型不通过瞬间停车或搬动位置掩盖失败。

④ 空间不足就等待，通过后恢复

当纵向和横向都无法继续推进时，主体可以停车等待；横向分离达到要求后，再受加速度限制恢复通行。模型不包含倒退、掉头、路外借道、交替放行协议或避车港，因此某些场景会持续等待或形成僵持。

FREE、BRAKE、SIDESTEP、WAIT、PASS、RECOVER、FOLLOW 是对当前动作的记录标签，分别表示自由运动、制动、侧移、等待、交会、回归路径和跟随；控制量始终来自上述共同方程。

3. 位置怎样更新，怎样检查碰撞

默认时间步 Δt = 0.05 s。每一步先让所有主体读取同一个旧状态计算控制量，再一起更新，避免后计算的主体看到别人已经更新的位置。

u_next = clip(控制器速度, max(0, u − a_brake Δt), u + a_accel Δt)
w_next = 满足横向速度、加速度及目标停止距离限制的控制量
s_next = s + d × u_next × Δt
y_next = y + w_next × Δt

这是半隐式 Euler 更新，每个时间步内按新速度线性移动。更新后检查整段运动中的矩形接触和道路边界，不能只看两端是否重叠，否则快速相向运动可能互相穿过而漏检。

  • 两个实体包络接触或重叠，记为碰撞；包络越过道路边界，记为越界。
  • 安全间距与实体尺寸分开记录。“没有接触”不等于“满足全部安全裕度”。
  • 开放道路中，主体尾部全部离开目标端才计为通过；最后一个主体离开的时刻才是总完成时间。
  • 默认直路最长观察 160 s。未完成时总完成时间为 null，不能用等待或失败发生时刻替代。

4. 为什么理论放得下，却仍可能过不去

需要区分三个层次：

层次 默认尺寸下的条件 含义
几何极限 W_geom = 1.8 + 0.6 = 2.4 m 恰好等于时没有裕度；贴合接触仍会被判碰撞
安全断面 W_safe = 1.8 + 0.6 + 2×0.1 + 0.2 = 2.8 m 同时容纳实体、两侧墙边裕度和双方间距
给定位置和能力下可达 还需检查固定车道位置、侧移能力和制动距离 总宽度够，不代表当前姿态或局部控制一定能通过

例如车宽 1.8 m 且固定在道路正中，行人只能从指定一侧绕行时，需要 W ≥ 3.6 m 才能保留上述安全间距；允许车辆靠边，可以释放这部分空间。宽度扫描从 5 m 降到 2.4 m，不低于默认几何下限。

只有所有未退出主体的二维速度都小于 0.025 m/s，并持续 8 s，才触发全体停滞诊断：

结果标签 解释
waiting_geometry 最窄断面不足以容纳两者实体宽度
waiting_clearance 实体可放下，但设定安全裕度不足
waiting_alignment 安全总宽足够，固定主体的位置堵住指定侧通道
deadlock_policy 上述条件未解释停滞，需要检查选边、机动能力或排斥作用
timeout 直路达到观察上限仍未全部离开；不直接等同于死锁

这些标签提供候选原因，断面条件不是整条道路可达性证明。缩窄道路还受会车位置、进入顺序影响；当前全体停滞检测也不能识别所有局部等待问题。详细事件定义和指标见规则与评价口径。

5. 圆环和社会力模型怎样接入

圆环向心穿越：默认4辆车、4个行人交替均匀排列在半径12 m圆周上，同时朝圆心出发，目标是各自圆周对侧。原速度、侧移和制动公式在每个主体自己的局部朝向坐标中计算；位置用二维向量更新，接触用固定朝向矩形的连续SAT检查。每个主体初始朝向固定，保留原模型的小幅侧移近似，不引入车身转向。到达对径目标0.35 m范围并停稳才计为完成，已经到达的主体仍占据物理空间。

这个场景没有环形道路或周期接缝。虚拟路径带只限定侧移目标，不作为实体墙；原道路断面阈值不能直接套用。默认4人4车在现有规则下出现僵持；单人单车的规则模型与修正版可通过。具体适配、120次结果及限制见向心实验说明。

**社会力模型（SFM）**将交互项换成期望速度松弛、主体指数排斥和软墙排斥，仍使用同样的尺寸、运动上限、更新器与碰撞检测：

a = (v_des − v) / tau + Σ A exp(−g/B) ω n + a_wall

其中 g 是按矩形包络适配的间距，n 是中心连线方向，ω 是方向权重；默认 A = 8 m/s²、B = 1.5 m，未用实测数据标定。

策略 主要处理
reciprocal 显式选边、窄路慢行、互惠制动
social_force 期望运动与指数排斥，不加入主模型的选边和制动包络
sfm_guided 在 SFM 上加入横向规划和规则速度上限，解除已横向分离的相向主体排斥

另保留 sfm_guided_ungated 作为中间修正：已有选边和制动，但仍保留已分离主体间的排斥。比较使用相同初态和种子，研究这些具体实现的差异。更完整的方程、假设和参考文献见模型说明。

7. 运行与扩展

需要 Python 3.9+；核心仿真、数据导出和回放只使用标准库。在本文件所在目录执行：

# 直路 / 圆环
python -m pvsim run --config configs/default.json --out results/custom
python -m pvsim run --config configs/ring.json --out results/custom_circle
# 社会力对照；将 social_force 换成 sfm_guided 可运行修正版
python -m pvsim run --config configs/default.json --policy social_force --out results/custom_sfm
# 全部实验与测试
python -m pvsim all --seeds 5 --out results
python -m unittest discover -s tests -v

单次运行输出 result.json、trajectory.csv 和 replay.html。修改 默认配置 调整宽度、速度、数量等；任意主体起点与尺寸参照 自定义布局。统计绘图需先安装 requirements-plot.txt，再为全部实验命令添加 --plots。重跑后可用 python -m pvsim.report --root . 更新 docs 中的实验报告和灵敏度表。
