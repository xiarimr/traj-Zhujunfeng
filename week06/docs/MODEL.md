# 模型定义与假设

## 1. 统一状态和动力学

每个主体 i 使用同一个状态 `z_i = (s_i, y_i, u_i, w_i)`：s 是纵向坐标，y 是横向坐标，u ≥ 0 是沿意图方向的速度，w 是横向速度；方向 d_i ∈ {−1,+1}。主体用长 l_i、宽 b_i 的轴对齐矩形包络表示，行人也使用保守矩形包络。车辆不作航向旋转。

共享的更新方程是：

```text
u_i(k+1) = clip[控制器给出的目标速度,
                max(0, u_i(k) − brake_i Δt), u_i(k) + accel_i Δt]
w_i(k+1) = 满足横向速度与横向加速度上限的控制量
s_i(k+1) = s_i(k) + d_i u_i(k+1) Δt
y_i(k+1) = y_i(k) + w_i(k+1) Δt
```

这是半隐式 Euler 离散化；每一步内位置按新速度线性移动。所有主体先读取同一时刻快照计算控制，再一起更新。制动能力不足时只按最大减速度刹车，仍可能碰撞；不会把位置投影到安全处，也不会瞬时置零速度。

车辆横向上限设为 0，就保持初始车道；设为 0.2 m/s，即允许缓慢靠边。行人默认 0.7 m/s。两类主体仍调用完全相同的 `ReciprocalPolicy.control`。

## 2. 统一规则交互模型

模型由期望运动、选边/路径保持、互惠制动包络和受限积分组成，是本实验构造的透明基线，不是完整 ORCA，也不是已经标定的社会力模型。

**期望运动。** 纵向速度向期望速度以 `speed_tau` 松弛。相向主体进入交互范围后，目标速度还受到交会速度限制。横向目标取可预见窄断面中的指定侧安全边界，控制 `w_des = clip[(y_target − y)/tau_y, −w_max, +w_max]`，并用横向停止距离限制接近目标的速度。默认行人选 +y 侧，车选 −y 侧；固定选边减少左右振荡。

**速度随宽度变化。** 设可用余量 `q = W_look − b_i − b_j − 2 margin_wall − gap_lateral`，交会速度系数为：

```text
f(q) = f_min + (1 − f_min) clip(q / q_comfort, 0, 1)
u_target ≤ encounter_speed × f(q)
```

默认 f_min = 0.35，q_comfort = 0.60 m。它是明确加入的“窄路慢行”行为假设。因此临界宽度附近变慢不是独立于假设得到的普适定律。宽路目标侧移更远，路径长度也可能增加，结果不必对宽度严格单调。

**冲突判断。** 当横向包络净间距 `|y_i − y_j| − (b_i+b_j)/2` 达到指定侧向间距时，解除相向纵向停车约束。使用当前与一小步外推的较小横向间距，避免仅凭侧移意图提前放行。实际接触仍由独立几何模块检测。

**互惠制动。** 对尚未横向分离的相向主体，令纵向前向包络间隔减去静态间距后的剩余距离为 D，双方各分配 λD，λ = 1/2。控制上限满足：

```text
u_i T + u_i² / (2 brake_i) ≤ λ max(D, 0)
u_safe = sqrt[(brake_i T)² + 2 brake_i λ max(D,0)] − brake_i T
T = reaction_buffer + Δt
```

`reaction_buffer` 是制动规划余量，不是已实现的感知延迟。遇到多个冲突取各上限的最小值。同向跟随使用前车静止的保守上限（λ=1），不假设前车必定继续运动。控制最终仍受最大制动能力约束，所以上限不构成任意初态下的无碰撞证明。

**质量。** 质量保留为元数据，不直接产生“轻者必须让重者”的规则。双方行为差异由尺寸、速度、纵横向机动能力和制动能力表达。本版 A、制动上限等都直接以加速度给定；若未来使用实际驱动力 F_max，可以通过 a_max=F_max/m 引入质量，而不是把质量当作路权。

## 3. 三种可通行条件

1. 几何极限：`W_geom = b_vehicle + b_pedestrian`。默认 1.8+0.6 = 2.4 m；等号是零裕度贴合极限，不代表严格无接触通行。
2. 安全断面：`W_safe = b_vehicle + b_pedestrian + 2 margin_wall + gap_lateral`。默认 2.8 m。
3. 给定位置和运动能力可达：若车固定在 y_v，指定行人侧剩余宽度仍须容纳行人和间距。对居中不动的车，单侧条件为 `W ≥ b_vehicle + 2 b_pedestrian + 2 margin_wall + 2 gap_lateral`，默认 3.6 m。

主宽度扫描为 5.0→2.4 m，不低于默认几何下限。安全下限以下可能仍几何可放下，却应在当前安全参数下等待。

这些是断面必要条件，不能证明沿整个道路存在可实现路径。缩窄道路还取决于会车位置、进入顺序、是否允许倒退和是否有避车区；本版不倒退、不借用路外空间。

## 4. 社会力基线与修正

社会力基线采用期望速度松弛、主体排斥和道路边界排斥的常见结构：

```text
a_i = (v_des − v_i)/tau_i
      + Σ_j A exp(−g_ij/B) ω_ij n_ij
      + a_wall
ω_ij = λ_aniso + (1−λ_aniso)(1+cos φ_ij)/2
```

`n_ij` 为中心连线方向。为了与规则模型使用相同实体尺寸，沿该方向用矩形 Minkowski 包络的有效半径替代圆盘半径：`r_eff = min(h_x/|n_x|, h_y/|n_y|)`，`g_ij = center_distance − r_eff`。这不是矩形距离的精确梯度，是明确的包络适配。两侧墙使用指数排斥；只考虑本处宽度，未自带前瞻路径规划。

SFM 同样受速度、加速、制动、横向速度和横向加速度限制，采用相同同步积分器及连续接触检测。A 的单位为 m/s²，B 为 m。本次使用 A=8、B=1.5 作为工程默认值，并保留 A∈{2,4,8,16}、B∈{0.4,0.8,1.5,2.5} 的参数探索；没有实测标定。默认值参考了单人单车种子100的探索结果，参数表公开全部探索结果，不能把它称为盲测优化结果。

三组正式比较：

| 策略 | 纵向交互 | 横向交互 | 已消除冲突的处理 |
|---|---|---|---|
| reciprocal | 期望速度与制动包络 | 显式选边和路径保持 | 横向分离后解除停车约束 |
| social_force | 期望速度与指数排斥 | 期望路径与指数排斥 | 保留距离排斥 |
| sfm_guided | SFM 纵向速度与规则上限取小 | 使用规则规划的横向控制 | 横向已分离的相向主体不再施加 SFM 排斥 |

另有 `sfm_guided_ungated`：加入选边和制动，但没有解除已消除的排斥，作为中间修正失败对照。修正版明确引入了额外规划和约束，不再是纯 SFM。实验只比较这些具体实现与参数，不能推断所有社会力模型都不如规则模型。

## 5. 圆环实验

圆环采用周期展开坐标 `(s mod L, y)`。主体位置 s 保持展开值，以统计路程和圈数；交互选取周期近邻，连续接触检查覆盖邻近三个周期镜像，接缝不能漏检。默认周长 80 m、观察期 180 s。

圆环没有终点退出，不能使用“所有人车最终通过”作为结束条件。主要指标是观察期是否完整、相向互过次数、s=0 检测线累计通过次数、累计完整圈数、间距、等待与失败。因失败提前终止的环道运行，以计划的180 s作为吞吐分母，相当于失败后运动贡献为零，避免短暂高速失败被误认为高效率。

圆形画面是周期坐标的映射，矩形包络在图中映射为环带扇形。它适合对照周期拓扑、重复会遇和排队，不模拟刚体车辆航向、不同半径的真实路程、离心效应或弯道扫掠。真实圆形道路实验需另加 Frenet/自行车模型及旋转矩形几何。
