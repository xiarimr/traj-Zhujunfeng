根目录的 index.html 是向心动态主页，README 是模型说明入口；其他 Markdown 收纳在 docs。网页文档导航将模型、规则、参数、实验和综合记录连接起来，每份 Markdown 都有同名 HTML，各页面提供章节目录与回放入口。交互回放及其模板、原始数据、图片和代码保留。源码在 pvsim，场景配置在 configs，测试在 tests。

修改 Markdown 后，在根目录执行 python -m pip install -r requirements-docs.txt（首次安装），再执行 python -m pvsim.render_docs --root . 更新 HTML；该命令不重新运行实验。
