# 参数表

除文献模型结构外，下列数值均为本原型的工程假设；没有以现场数据标定。单位统一为 m、s、kg。随机种子控制速度扰动，不引入随时间的随机行走噪声。

## 主体参数

| 参数 / 代码键 | 行人 | 车辆 | 说明 |
|---|---:|---:|---|
| 长度 `length` | 0.5 m | 4.5 m | 纵向矩形包络长度 |
| 宽度 `width` | 0.6 m | 1.8 m | 横向实体宽度，不包含安全裕度 |
| 期望/初始速度基值 | 1.3 m/s | 3.0 m/s | 同一种子在两种/三种模型中相同 |
| 速度扰动 `speed_jitter` | ±8% | ±8% | 均匀分布，初始速度等于扰动后的期望速度 |
| 纵向最大加速度 `max_accel` | 1.2 m/s² | 1.5 m/s² | 两侧使用同一限幅公式 |
| 最大制动 `max_brake` | 2.0 m/s² | 3.0 m/s² | 不允许瞬间停车 |
| 横向最大速度 `lateral_speed` | 0.7 m/s | 0 m/s；对照0.2 | 车辆默认固定横向位置 |
| 横向最大加速度 `lateral_accel` | 1.0 m/s² | 0.4 m/s² | 小幅侧移的机动限制 |
| 纵向松弛时间 `speed_tau` | 0.7 s | 0.7 s | 不等于感知反应时间 |
| 横向松弛时间 `lateral_tau` | 0.8 s | 0.8 s | 跟踪横向目标 |
| 交会速度上限 `encounter_speed` | 1.0 m/s | 1.0 m/s | 主规则按宽度再乘0.35～1系数；纯SFM不用该规则 |
| 意图方向 `direction` | −1 | +1 | 相向运动 |
| 避让侧 `side` | +1 | −1 | 默认固定选边，保持到错车完成 |
| 质量 `mass` | 70 kg | 1500 kg | 元数据；质量×0.1/1/10为无影响对照 |

| 直路长度 | 60 m | 目标是主体尾部离开道路 |
| 基础宽度 | 3.2 m | 主宽度扫描5.0→2.4 m |
| 行人数 / 车数 | 3 / 2 | 不是连续到达过程，所有主体t=0已在路中 |
| 车辆起点s | 16、7 m | 车中心间隔9 m |
| 行人起点s | 44、46.5、49 m | 人中心间隔2.5 m |
| 初始相向中心距 `initial_gap` | 28 m | 主扫描12、20、28、34 m；不是表面净距 |
| 初始车道位置 | −W_min/2 + 0.1 + 1.8/2 | 根据最窄宽度提前靠边；居中另作对照 |
| 行人初始y / home_y | 同车辆初始y | 初始确实存在迎面冲突 |
| 缩窄道路宽度节点 | (0,5),(12,5),(18,W),(42,W),(48,5),(60,5) | 按s线性插值，静态空间缩窄 |

| 制动规划余量 `reaction_buffer` | 0.6 s | 本版不模拟信息延迟 |
| 人车侧向间距 `lateral_clearance` | 0.2 m | 扫描0、0.1、0.2、0.3、0.4 m |

| 持续停滞时长 `stall_time` | 8 s | 所有未退出主体同时低速 |

| 回放采样间隔 | 0.20 s；批量对照0.50 s | 只影响保存与显示，不影响0.05 s仿真 |

## 社会力参数

| 参数 | 默认值 | 探索范围 / 含义 |
|---|---:|---|
| A | 8 m/s² | {2,4,8,16}，主体排斥幅值 |
| B | 1.5 m | {0.4,0.8,1.5,2.5}，排斥衰减距离 |
| wall_A | 3 m/s² | 软墙排斥幅值 |
| wall_B | 0.2 m | 软墙作用距离 |
| anisotropy | 0.3 | 后方作用权重下限 |

A、B 探索在3.2 m、单人单车、种子100–102上完成；模型对照在少量多人多车、种子0–4上完成。只探索了有限参数，没有声称求得全局最优值。wall_A、wall_B、各向异性和行人个体差异尚未全面标定或搜索。

## 向心穿越参数

| 参数 | 默认值 | 对照 |
|---|---:|---|
| 初始半径 radius | 12 m | 8、12、16 m |
| 人车对数 pairs | 4，即4人4车交替排布 | 1、2、4、6 |
| 观察时长 duration | 120 s | 固定 |
| 侧移目标 passing_offset | 2.5 m | 固定；局部+n方向 |
| 终点容差 goal_tolerance | 0.35 m | 进入范围并停稳才完成 |
| 车横向速度上限 | 0 m/s | 0.2 m/s |
| 车初始/期望速度 | 3 m/s | 1.5 m/s |
| 圆周整体旋转 rotation | 0 rad | 旋转不变性测试0.371 rad |

向心实验复用主体尺寸、加减速、时间步及速度扰动；没有实体环道或墙力。8个配对设计共120次，详见[CIRCLE.md](CIRCLE.md)。
