# 更新规则、诊断与评价口径

## 每个时间步

1. 对所有未退出主体读取同一个旧状态快照；周期道路先构造近邻镜像。
2. 同一策略根据期望运动、道路、相对位置和主体能力产生控制量。主模型和 SFM 不通过 `kind` 判断行人或车辆。
3. 受限积分得到下一状态；不覆盖速度上限不足所产生的真实制动过程。
4. 检查整个线性位移段的矩形接触、最近间距，以及分段线性道路边界。圆环同时检查接缝镜像。
5. 记录碰撞、越界、互相通过、出口离开/环道检测线通过等事件。
6. 达到退出、失败、持续停滞或观察时限条件后停止，输出原始轨迹与指标。

## 交互规则

- 默认车向 +s、人向 −s；人选 +y 侧、可侧移车辆选 −y 侧。车辆横向能力为零时保持初始位置。
- 相向近邻使用固定侧目标，直到对方尾部及纵向间距都已经通过，才恢复初始路径。多个来车持续保持交互状态。
- 未实现动态路权、倒退、掉头、外部信号、停车港湾或智能体之间的显式协商。因此无解时等待是允许的结果。
- 默认车辆起点根据最窄宽度预先靠边，**宽度实验不是“车永远居中”**。居中不动与允许侧移另外对照，避免把额外占位限制混入几何下限。
- SFM 的软墙不等于硬约束。越界即记录失败，不能通过裁剪位置掩盖。

## 状态和终止分类

| 分类 | 条件/解释 |
|---|---|
| completed | 开放道路中所有主体的尾部均已离开目标端 |
| sustained | 周期道路运行到完整观察期，未先触发碰撞、越界或全体停滞；不是无限时域稳定性证明 |
| collision | 连续步内检测到两个物理矩形包络接触或重叠，接触也计为碰撞 |
| boundary_violation | 物理包络离开道路边界 |
| waiting_geometry | 全体未退出主体持续低速，且最窄断面不满足几何必要条件 |
| waiting_clearance | 全体持续低速，几何可放下但安全断面条件不满足 |
| waiting_alignment | 全体持续低速，安全总宽足够但固定主体的位置阻塞指定侧通道 |
| deadlock_policy | 全体持续低速，以上断面条件未解释停滞；需查看运动能力、选边、排斥力与局部目标 |
| timeout | 开放道路达到观察时限仍未全部退出，不能等同于死锁 |

停滞判据：所有未退出主体二维速度模长小于 0.025 m/s，持续 8 s。短暂停车后恢复不算死锁，持续横移也不算停滞。当前是全体停滞检测，不能保证发现“部分主体永久等待、其他主体仍在动”的所有情况。

诊断由几何条件分层给出，属于候选原因解释。尤其对任意新道路或纯 SFM，不能把断面检查直接当作因果证明。数据中同时保留间距、位置、事件和策略名，以便复查。

## 指标

| 字段 | 单位与含义 |
|---|---|
| completion_time_s | 最后一个主体尾部离开时间；未完成为 null |
| observation_time_s | 仿真实际观察时长；等待/碰撞时不等于完成时间 |
| pedestrians_passed / vehicles_passed | 开放道路中完成退出的唯一主体数 |
| pair_passages | 相向主体尾部相互错开且保留纵向间隔的事件数；环道可重复 |
| detector_crossings | 环道 s=0 检测线累计通过次数，不是唯一人数/车数 |
| total_laps | 各主体从初始位置起完成的整圈数之和，不等于检测线通过数 |
| min_pair_gap_m | 整个步内所有物理包络的最小欧氏间距；不是单独的横向间距 |
| min_wall_gap_m | 所有运动段内主体到墙的最小净间距 |
| safety_margins_satisfied | 无碰撞越界，且最小物理间距和边界间距满足设定裕度（含 1e−5 m 数值容差） |
| total_agent_waiting_s | 各主体低速等待时间之和，是“主体·秒”，可以大于仿真时长 |
| speed_ceiling_unreachable_agent_steps | 当前保守目标上限无法在一步内达到的主体步数，不等同于必然碰撞 |
| mean_longitudinal_speed_m_s | 已观察时段中平均纵向进展速度；跨不同失败时刻比较需谨慎 |
| effective_speed_planned_horizon_m_s | 环道累计进展除以计划观察时长及人数，提前失败后按零新增进展计 |
| pair_passages_per_min_planned | 环道互过事件除以计划观察时长的每分钟值 |

开放道路输出的每分钟通过数是有限初始批次的观察值，不能直接称为稳态道路容量。主要报告完成率、条件完成时间、间距和停滞分类。

## 公平对照与边界

三种模型使用同一场景对象的深拷贝：道路、尺寸、初始位置、速度、加减速上限、横向能力、步长、碰撞检测、退出定义和停滞判据相同。每个配置采用相同种子0–4，随机性只来自期望/初始速度的±8%独立扰动。

纯 SFM 没有主模型的显式窄路慢行、选边和制动包络；这是待比较的策略差异，不是积分器差异。它也没有数据标定或完备的路径规划。因此结果支持“本实现的行为差异和修正效果”，不支持现实交通安全性能、所有社会力模型排名或一般性的无碰撞保证。
