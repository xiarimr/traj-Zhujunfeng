# Week 07：100 架无人机三维球面对径飞行

仿真已完成。100 架无人机近似均匀分布在半径 **15 m** 的球面上，同时飞向各自对径目标；采用**目标吸引 + 预测避碰 + 环流破对称 + 安全速度投影**模型。

## 均匀球面布点

对 `i = 0,...,99`：

```text
z_i   = 1 − 2(i + 0.5)/100
phi_i = i × π(3 − √5)
p_i   = R × (√(1−z_i²) cos(phi_i), √(1−z_i²) sin(phi_i), z_i)
```

`z` 等间隔对应等面积球面带，黄金角经度避免沿少数离散纬圈排布。这里的“均匀”指有限点集的近似均匀覆盖，不是所有两点距离相等。初始最近机间距为 **4.63556 m**，各机最近邻间距的变异系数为 **1.887%**。无随机种子，同样输入可重复得到同一结果。

## 运动模型

代码位于 [simulation.py](simulation.py)，只依赖 NumPy。本模型是为该课堂场景构造的速度级控制器，没有使用或声称实现完整的 ORCA 算法。

1. **目标吸引**：期望速度朝向对径目标，大小为 2 m/s。
2. **环流破对称**：在球心附近叠加绕固定倾斜轴的切向速度，最大 1.2 m/s，在球面附近及接近目标时平滑减弱，避免完全正面对冲造成的对称停滞。
3. **5 秒冲突预测**：基于当前期望速度计算每一机对未来最近接近时刻。如果预测间距小于 2 m，则沿最近接近位置的分离方向添加互惠速度修正；若对方已到达停留，则由运动方承担避让。
4. **速度安全投影**：修正可能在下一个时间步内进入危险距离的机对速度，并反复施加 2 m/s 速度上限。到达者始终固定。内部迭代只修改待执行速度，最后统一更新位置。

设旧位置相对向量为 `r = p_i − p_j`，`d = |r|`，`n = r/d`，控制器要求：

```text
n · (v_i − v_j) ≥ −(d − 1.02) / Δt
```

在整个同步直线积分段 `0 ≤ s ≤ Δt` 内，`n · [r + s(v_i − v_j)] ≥ 1.02`，因此相对距离也不小于 1.02 m。只需包含当前距离不超过 `1.02 + 2 vmax Δt` 的机对，因为其余机对受速度上限限制，不可能在一步内进入安全距离。若迭代存在残差，代码统一缩放待执行速度使约束成立；本次运行没有触发实质性缩放。

所有位置均通过 `p_next = p + Δt v` 更新，没有通过移动已有位置或瞬移消除碰撞。预测避碰改善路线，安全投影负责保证单步间距。

## 结果与失败对照

| 指标 | 预测避碰主模型 | 直线飞行失败对照 |
|---|---:|---:|
| 到达率 | 100% | 100%（忽略碰撞后继续飞行） |
| 全部到达时间 | 18.60 s | 14.50 s |
| 全过程最小间距 | 1.020068 m | 约 0 m |
| 侵犯 1 m 间距的不同机对数 | 0 | 4950 |
| 最大速度 | 2.00 m/s | 2.00 m/s |
| 平均累计路程 | 31.33890 m | 29.00000 m |
| 最大最终目标误差 | 0.99658 m | 1.00000 m |

**失败解释：**直线对照没有避碰项。所有无人机到球心的距离都是 15 m，速度都是 2 m/s，因此在约 7.5 s 时同时穿过球心，全部 `100×99/2 = 4950` 个机对均侵犯安全距离。其较短到达时间不能视为有效的安全飞行结果。主模型通过侧向绕行、局部速度调整增加少量路程，从而完成安全对径交换。

指标口径：

- **最小间距**：每个时间步内对机对相对运动作二次函数最小化，检查整个连续线段，不只检查离散帧。
- **违规机对数**：全过程曾低于 1 m 的不同无序机对数量，不是违规帧数。
- **累计路程**：每架无人机逐步位移长度之和，再取 100 架平均值。
- **到达时间**：首次满足 1 m 容差的采样时刻；停留位置不强行吸附到目标。
- 浮点检查使用 `1e-9` 容差，因此 JSON 中 `2.0000000000000093` 等数值视作 2 m/s。

## 验证

[validate.py](validate.py) 已实际运行通过：

- 独立复核 **4950 个机对、186 个时间区间**的连续最小距离；结果与仿真器一致。
- 检查 100 架数量、球面半径、对径目标、零初速、速度上限、到达率、到达后静止和时间限制。
- 构造“两个端点均安全，但步内交叉碰撞”的案例，确认检查器能识别帧间碰撞。
- 同参数重跑，完整位置数组完全相同。
- 将时间步减半至 **0.05 s**：仍为 100/100 到达、违规机对 0；全部到达时间 **18.55 s**，最小间距 **1.020014 m**，平均路程 **31.27836 m**。
- 已用 Edge 实际检查离线页面加载、进度拖动、模型切换、播放暂停、显示开关和窄屏布局，未出现页面脚本错误；[回放预览](results/replay_preview.png)。可选的浏览器检查脚本为 `check_replay.cjs`，需要另备 Node.js、Playwright 和 Edge，不影响运行仿真或浏览已有结果。

这里完成的是指定场景下的运动学仿真；没有加入加速度、姿态、风扰动或通信延迟，也不声称上述单次场景验证代表其他密度和参数下都可完成。

```powershell
python -m pip install -r week07/requirements.txt
python week07/simulation.py --baseline
```
